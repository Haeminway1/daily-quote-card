# GAS Wrapper Template

This directory is tokenized by `tools/build-wrapper.mjs` into
`<runtimeDir>/wrapper-build/`.

Tokens come from `gas.project.json`:

- `quotecard`
- `__APP_NAME__`
- `__SHORT_NAME__`
- `__THEME_COLOR__`
- `__GAS_ORIGIN__`
- `__WRAPPER_ORIGIN__`

The PNG files are placeholder install icons. Replace them with project-owned
assets before customer deployment.
